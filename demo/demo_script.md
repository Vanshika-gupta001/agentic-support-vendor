# Demo video script (3-5 min)

1. **Intro (20s)** — problem statement, why it needs an agentic approach
2. **Case 1 — support, auto-resolved (60s)** — submit a simple ticket, show
   classification -> KB search -> evaluation -> auto-resolved response
3. **Case 2 — vendor, escalated (60s)** — submit a vendor query that fails
   the price threshold, show the agent's reasoning and the escalation log
4. **Failure / adaptation moment (30s)** — deliberately trigger an edge case
   (e.g. no KB match) and show how the agent adapts / escalates instead of
   breaking
5. **Wrap-up (20s)** — recap architecture, mention deployed link / repo
